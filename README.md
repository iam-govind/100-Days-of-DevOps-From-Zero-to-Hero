# 🚀 100 Days of DevOps — From Zero to Hero

Welcome to my **100 Days of DevOps** journey!

I started this repository to document my journey of learning DevOps from the fundamentals and gradually moving toward building and deploying a complete end-to-end DevOps project.

The goal is simple:

> **Learn → Practice → Build → Document → Share**

Over the next 100 days, I will learn DevOps concepts, complete hands-on labs, document what I learn, and build practical projects.

---

## 🎯 Goals of This Journey

By the end of these 100 days, I aim to:

* Build a strong understanding of DevOps fundamentals
* Become comfortable working with Linux
* Understand networking concepts required for DevOps
* Learn Git and GitHub for version control
* Containerize applications using Docker
* Gain hands-on experience with Azure
* Build CI/CD pipelines
* Learn Kubernetes fundamentals
* Provision infrastructure using Terraform
* Automate tasks using Ansible
* Monitor applications and infrastructure
* Understand DevSecOps fundamentals
* Build an end-to-end DevOps project

## 💻 Hands-on Approach

This repository is not intended to contain only theoretical notes.

For each topic, I aim to follow this approach:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Break Things
  ↓
Troubleshoot
  ↓
Fix
  ↓
Document
  ↓
Share
```

I believe hands-on practice is one of the best ways to learn DevOps.
